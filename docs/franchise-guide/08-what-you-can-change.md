# 8. What you can change

The dashboard is built so that you control your own business and MuscleBoxPro keeps control of
anything that touches payments, security, refunds, customer data or every machine at once.

- **Change**: you can edit it.
- **View**: you can see it, not change it.
- **MBP**: handled by MuscleBoxPro for you.

## Machines

| Area | What | You |
| --- | --- | --- |
| Fleet | Machine list, health tiles, today's orders and sales | View |
| Fleet | Add a new machine to the system | MBP |
| Settings | Name, service phone, address and location | Change |
| Settings | Hot and cold water limits | Change |
| Settings | Enable or disable a machine | Change |
| Settings | Machine number, model, hardware, first and last seen | View |
| Settings | QR payment and free vend | View |
| Owner | Current owner and history | View |
| Owner | Moving a machine to another gym or franchise | MBP |
| Goods | List or unlist a drink, add goods, set machine price, sort order | Change |
| Stock | Canister levels and restock history | View |
| Stock | Restock or correct a level | Change |
| Voice prompts | This machine's own prompts | Change |
| PINs | Operator PIN | Change |
| PINs | Factory PIN | MBP |
| Remote control | Clean, door, lock, unlock, water, re-read, restart, reboot | Change |
| Remote control | Live status | View |
| Remote control | Pairing the machine for remote control | MBP |
| Logs | Equipment log and operations log | View |
| Logs | Technical log files, crash reports and configuration backups | MBP |

## Sales and customers

| Area | What | You |
| --- | --- | --- |
| Orders | Every drink ordered, with CSV export | View |
| Statistics | Orders, sales and ads by day, month or year, with CSV export | View |
| Feedback | Read customer messages with their contact details | View |
| Feedback | Mark New, Replied or Closed, and add a note | Change |
| Redeem codes | See codes that work on your machines | View |
| Redeem codes | Create, edit or disable codes | MBP |
| Shop orders | Website orders for your machines | View |
| Shop orders | Refunds and re-issuing codes | MBP |
| Customers | Shop customers, stamps and balances, and balance refunds | MBP |

Shop customers can buy at any machine, and their balance is MBP's money held for them, so
customers and every refund stay with MBP.

## Menu

| Area | What | You |
| --- | --- | --- |
| Goods library | Drinks, pictures, recipes and library prices | View |
| Materials | Canister names, slots, capacities and warning levels | MBP |
| Discounts | Discounts running on your machines | View |
| New products | New-product promotions | MBP |

You pick from MBP's goods library and set the machine price within your agreement's pricing
framework. Recipes and materials stay with MBP, because a wrong recipe would make a bad drink on
every machine.

## Team

| Area | What | You |
| --- | --- | --- |
| Operators | See your operators | View |
| Operators | Create, edit, set passwords, turn on or off | Change |

## Inventory and assets

MBP's own inventory, warehouses, cost of drinks and machine asset records are not part of the
franchise dashboard.
